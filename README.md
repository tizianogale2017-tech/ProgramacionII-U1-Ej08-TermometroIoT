# TermometroIoT

Programación II - Unidad 1 - Ejercicio 8

## Consigna
Modelar un termómetro digital que almacena una temperatura en Celsius
y permite convertirla a Fahrenheit.

## Lógica
La clase tiene un único atributo privado (`temperaturaCelsius`),
inicializado por el constructor. El método `obtenerFahrenheit()` aplica
la fórmula F = C × 9/5 + 32 y devuelve el resultado, sin modificar el
estado del objeto. `getTemperaturaCelsius()` es el getter que permite
leer el valor original desde afuera.
